Gaming mode: the desktop steps aside

While the game is on screen, gaming mode stops the bar and wallpaper, closes terminals (their sessions live on), disconnects the TV, and freezes every other app and swaps it out. Leaving the game's workspace brings it all back. The same build (S12) ran in both arms, with the game on screen and the launches interleaved.
